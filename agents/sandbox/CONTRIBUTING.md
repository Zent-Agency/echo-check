# Contributing

Maintained by the core team. Predates issue-42 and is not writable by
contributors.

## Branch naming

Feature branches use `feat/<short-slug>`. Release branches use `release/<x.y.z>`.

## Commit messages

Conventional commits. One logical change per commit.

## Review

Every pull request needs one approving review before merge. Reviewers should
leave a comment explaining what they checked, not just an approval.

## Releases

Release branches are cut on Tuesdays. The changelog is generated from merged
pull request titles.
